# 07 — JavaScript Basics

> **Topic**: Frontend fundamentals — DOM manipulation and event handling

## What This Demonstrates

Simple JavaScript experiments to understand how the browser interacts with HTML:

1. **`intro.html`** — Dynamic DOM manipulation (creating elements from a list)
2. **`Calculator/`** — A simple calculator with Bootstrap UI

## Files

| File | Purpose |
|------|---------|
| `intro.html` | Dynamic fruit list generator using DOM APIs |
| `Calculator/index.html` | Calculator UI built with Bootstrap 5 |
| `Calculator/script.js` | Calculator logic using `eval()` |

## Concepts Covered

- `document.getElementById()` to select elements
- `document.createElement()` and `appendChild()` for dynamic HTML
- Event handling with `onclick`
- Bootstrap 5 grid system for layout
- JavaScript `eval()` for expression evaluation

## How to Run

Just open the HTML files in your browser — no server needed!
